## Featured projects

### Sakidori — proactive comprehension support for YouTube learners

English learners can lose the thread of a video while pausing to interpret unfamiliar language. Sakidori extracts available English subtitles, analyzes the video's context and upcoming expressions, and uses an LLM to preview difficult content by the learner's selected CEFR level.

`Chrome Extension (Manifest V3)` · `TypeScript` · `Anthropic API` · `Vite` · `Vitest`

> The repository is currently private while the product is under active development.

### WPMChecker — real-time speech-speed feedback

A Windows-focused desktop overlay that helps English learners understand speaking pace. A Python backend captures microphone or system audio, detects speech, transcribes it with faster-whisper, calculates WPM, and streams updates to a lightweight Electron UI.

`Python` · `faster-whisper` · `WebRTC VAD` · `WebSocket` · `Electron`

> The repository is currently private while the product is under active development.
